# 🕵️‍♂️ لعبة فاهي (Fahey Game) — مين اللي برا السالفة؟

لعبة ذكاء وتخمين اجتماعي جماعية (Pass & Play) تفاعلية تدعم 3 لهجات عربية أصيلة:
- 🇸🇩 **اللهجة السودانية:** «فاهي» (أفرز الفاهي القاعد بيناتنا وما جايب خبر!)
- 🇸🇦 **اللهجة السعودية:** «برا السالفة»
- 🇪🇬 **اللهجة المصرية:** «في الطراوة»

## ✨ المميزات
- 📱 **تطبيق ويب تقدمي (Offline-First PWA):** يعمل بالكامل بدون إنترنت بعد التحميل الأول بفضل Service Worker (`sw.js`).
- 🎨 **تصميم نهاري مشرق ومتجاوب (Mobile-First):** مصمم خصيصاً لشاشات الهواتف (375px+) بتجربة لمس سلسة.
- 🔊 **مؤثرات صوتية تفاعلية (Web Audio API):** أصوات حماسية مدمجة بدون ملفات صوتية خارجية، مع رادار ترقب ونبضات قلب درامية قبل كشف الحقيقة.
- 🗂️ **أقسام متنوعة ومخصصة لكل لهجة:** أكلات شعبية، معالم ومناطق، مصطلحات وكلمات دارجة، مهن، حيوانات، وغيرها.
- 🏆 **نظام نقاط ذكي:** يحفظ أسماء اللاعبين ونقاطهم تلقائياً في المتصفح (`localStorage`).

## 🚀 طريقة التشغيل محلياً
افتح ملف `index.html` مباشرة في المتصفح أو شغل خادم محلي بسيط:
```bash
npx serve .
```
